① 粘贴合同文本

支持「第3.2条」「第3.2.1条」「第五条」及「1.2」层级编号；支持「第5条至第7条」区间引用

    生效版本签发

    签发将一次性固定正文、顺序、删除状态与术语忽略项，重跑引用与术语终审；存在未解决问题或草稿在签发期间被修改都会被拒绝，且不改动草稿

    已签发版本（不可变）

    后续编辑只产生新版本，不会覆盖已签发版本；重复提交同一份草稿返回原版本。点击版本查看并定位签发时的正文、编号、引用改写与术语绑定

    版本差异审计

    选择同一草稿的两个已签发版本：按原条款稳定 ID 对齐两份不可变快照，区分正文改变 / 层级顺序调整 / 删除新增 / 仅编号改写，并逐条比较引用目标、区间表达与术语绑定；对目标删除或绑定改变的差异给出最短受影响链（循环组合并）。审计只读版本快照，草稿后续编辑或删除均不影响结果
